Quirl is a Rust shell that keeps your Bash and Zsh muscle memory working
natively, adds an explicit typed data mode for structured pipelines, and
standardizes configuration, scripts, prompts, completions, and trusted plugins
on one sandboxed Lua 5.5.1 SDK. Quirl 0.3.0 includes this runtime; historical
`v0.1.0` artifacts retain their recorded Lua 5.4 runtime.

The native binary remains usable offline. Compatible completion knowledge is
delivered separately through an exact-version website channel, so its immutable
database generations can improve without manufacturing an otherwise empty
binary release.
