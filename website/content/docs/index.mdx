Quirl is a Rust shell that keeps your Bash and Zsh muscle memory working
natively, adds an explicit typed data mode for structured pipelines, and
standardizes configuration, scripts, prompts, completions, and trusted plugins
on one sandboxed Lua 5.4 SDK.

<Callout type="warn" title="Pre-release documentation">
  Quirl 0.1 is an unreleased Unix candidate implementation and a fast-moving
  prototype. Some interfaces will change before the first tagged release. Linux
  and macOS are the supported interactive targets; Windows is best-effort
  portability work. Historical benchmark records apply only to their named
  artifacts, not to this candidate.
</Callout>
