## Release status

Quirl is a fast-moving, unreleased 0.1 prototype. The Unix candidate
implementation is integrated, but no stable version or measured current release
artifact has shipped. The remaining release work is tracked in the
[release checklist](/docs/project/release-0.1/release-checklist). Canonical
evidence attribution appears below.
