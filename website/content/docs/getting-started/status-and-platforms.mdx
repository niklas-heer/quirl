## Release status

Quirl is a fast-moving, unreleased 0.1 prototype. The Unix candidate
implementation is integrated, but no stable version or measured current release
artifact has shipped. The remaining release work is tracked in the
[release checklist](/docs/project/release-0.1/release-checklist); its benchmark
record is historical until it is replaced with evidence for the selected
candidate.

| Target | Status | Notes |
| --- | --- | --- |
| Linux | Supported candidate | Interactive and non-interactive release target |
| macOS | Supported candidate | Interactive and non-interactive release target |
| Windows | Best effort | Contract-tested portability; not a supported interactive target |
| WebAssembly packages | Validation only | Packages validate, but do not execute |

<Callout type="info" title="Expect change">
  Commands, contracts, and documentation will continue to evolve before the
  first tagged release. Accepted ADRs and frozen protocol descriptors identify
  the parts that are intentionally stable within the candidate.
</Callout>

For the current security-reporting policy, see [Security](/docs/project/security).
