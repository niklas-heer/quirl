## Release status

Quirl's 0.1 line supports interactive Linux and macOS. A build is an official
release only when an immutable GitHub tag and release name its exact commit;
untagged source checkouts are candidate or development builds even when their
workspace version is `0.1.0`. Release gates are tracked in the
[release checklist](/docs/project/release-0.1/release-checklist), and canonical
evidence attribution appears below.
