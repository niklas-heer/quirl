## Release status

Quirl's 0.3 line supports interactive Linux and macOS. A build is an official
release only when an immutable GitHub tag and release name its exact commit;
untagged source checkouts are candidate or development builds even when their
workspace version matches a release. Release gates are tracked in the
[release checklist](/docs/project/release-0.1/release-checklist), and canonical
evidence attribution appears below.

The current supported release is
[v0.3.0](https://github.com/niklas-heer/quirl/releases/tag/v0.3.0), from commit
`dfb43e54320d166ebe195bb5a0255b8aacbb11e5`. Install through Homebrew or use the
verified native archive for your Linux/macOS target. Check `quirl --version`
before following the 0.3.0 walkthrough. Compatible
completion knowledge may advance independently through the version-scoped
website asset channel without changing the binary version.

The [v0.3.0 native release measurements](/docs/research/benchmarks/release-v0.3.0)
identify all four published executables, their hosted runner environments,
and the passing latency and evidence gates. The 0.1 evidence block below
remains historical.
