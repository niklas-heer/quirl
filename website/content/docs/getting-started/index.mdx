Start Quirl inside your existing shell, run a familiar command, then try a
self-contained typed-data pipeline. The [first session](/docs/getting-started/first-session)
takes about five minutes, needs no account or sample files, and shows how to
return to your previous shell.

## The mental model

| Surface | Carries | Use it for |
| --- | --- | --- |
| Normal mode | byte streams | familiar programs, redirects, jobs, Bash/Zsh islands |
| Data mode | typed values | records, tables, filtering, selection, structured output |
| AI mode (optional) | proposals from an installed, authenticated Codex CLI | describe an intent, then move a validated proposal into Normal mode for review |
| Lua scripting | bounded logic | configuration, scripts, prompts, completion, plugins |

Use `mode data` and `mode normal` to switch between typed values and familiar
commands. Lua is a scripting surface rather than another interactive mode.
The AI description here follows current source builds, not the published 0.1.0
artifact. AI planning sends the submitted intent and bounded catalog context to OpenAI;
it has no local planner fallback. Normal commands and Data mode work offline.
