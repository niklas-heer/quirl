Quirl is deliberately familiar at the prompt. Start with the commands you
already know, opt into typed data when rows and records are the right model,
use AI mode to discover or plan a command without executing it, and reach for
Lua when you need general-purpose logic.

## The mental model

| Surface | Carries | Use it for |
| --- | --- | --- |
| Normal mode | byte streams | familiar programs, redirects, jobs, Bash/Zsh islands |
| Data mode | typed values | records, tables, filtering, selection, structured output |
| AI mode | local command knowledge plus optional Codex planning | describe an intent, then insert a validated proposal for review |
| Lua 5.5.1 | bounded logic | configuration, scripts, prompts, completion, plugins |

No mode silently pretends to be another. Native Quirl scripts make their
grammar boundaries visible, and values crossing the Lua boundary are validated
by Rust.
