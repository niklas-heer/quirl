- [Quirl 0.2.0 native release evidence](/docs/research/benchmarks/release-v0.2.0): historical measurements of the published 0.2.0 executables.

The project records executable size and advisory warnings without a default size ceiling. Latency, artifact identity, sample completeness, bounded retention, and process cleanup remain release requirements. Hosted PTY results and automated recordings do not substitute for human or physical-terminal review. The [release checklist](/docs/project/release-0.1/release-checklist) explains the candidate and evidence-commit distinction.
