---
title: Architecture decisions
description: The accepted records that define Quirl's extension language, layering, protocols, process boundaries, and release scope.
---

Architecture decision records capture decisions that should not drift while
implementation moves quickly. Read them as constraints on the current design,
not as a general roadmap.

The sequence begins with Lua as the sole extension language and crate layering,
then follows the runtime, contract, plugin, protocol, process, testing, release,
and interactive-surface decisions through ADR 0012.
