---

Quirl prioritizes safety, performance, and developer experience—in that order.
Changes should preserve user data, terminal state, process lifecycle, capability
boundaries, and deterministic resource limits before adding surface area.

## Before opening a change

```sh
cargo xtask check
```

Use the focused tasks while iterating:

```sh
cargo xtask fmt
cargo xtask lint
cargo xtask test
```
